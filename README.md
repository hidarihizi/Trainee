# NTT Stock Investment Optimizer (LightGBM-based)

NTT株を対象とした、月次積立投資の「エントリータイミング最適化」AIモデルです。

## 1. プログラムの概要
本プログラムは、新NISA等で毎月一定額を投資する「積立投資家」を支援するために開発されました。
一般的に、積立投資は「毎月決まった日に買う」のが定石ですが、本モデルは「月内のボラティリティを利用し、より安いタイミングで買う」ことで、中長期的な取得単価（平均取得価格）を抑制することを目指します。

ターゲットは「日中は多忙で相場に張り付けないが、朝の数分で賢い投資判断を下したいエンジニア」とし、実用性を重視した設計を行っています。

## 2. 技術的な特徴

### 特徴量エンジニアリング（Feature Engineering）
株価の単純な推移だけでなく、以下の投資指標（インジケーター）を算出し、AIの判断材料として組み込んでいます。
- **RSI (Relative Strength Index)**: 「売られすぎ」水準を判定
- **移動平均乖離率**: 25日移動平均からの乖離を算出し、リバウンド可能性を評価
- **出来高変動**: 市場の関心度やトレンドの転換点を捉えるための加工

### アルゴリズムと最適化
- **モデル**: 勾配ブースティング決定木アルゴリズム `LightGBM` を採用。非線形な市場変動に対しても高い予測精度を発揮します。
- **ハイパーパラメータ最適化**: `Optuna` を用い、ベイズ最適化によるパラメータチューニングを実施したが、テストデータの正答率が訓練データのそれを大幅に下回ったので、廃止。
- **判定ロジックの最適化**: 単なる騰落予測ではなく、「バックテスト期間において最もリターンが高くなる購入しきい値（Probability）」を自動的に探索・設定します。

### 検証プロセス（Validation）
- **Fair Validation**: 未来のデータを使ってしきい値を決める「先読みバイアス」を排除するため、学習期間内のみで最適なしきい値を決定し、完全な未知データ（テストデータ）でその有効性を検証しています。
