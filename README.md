# NTT Stock Investment Optimizer

NTT株（9432）の月次積立投資において、AIを用いて「その月の最適な買いタイミング」を判定するツールです。

## 1. 概要
毎月一定額を投資する際、ランダムに買うのではなく、テクニカル指標に基づいたAI判定（LightGBM）を行うことで、取得単価の抑制を目指します。
本ツールを実行すると、実行日のデータに基づき「買いシグナル」か「様子見」かを出力します。

## 2. 実行方法

### データの準備
実行ディレクトリに `stock_price.csv`（NTTの株価データ）を配置してください。
CSVには以下のカラムが含まれている必要があります。
- `日付`, `終値`, `始値`, `高値`, `安値`, `出来高`

### ライブラリのインストール
以下のライブラリが必要です。
